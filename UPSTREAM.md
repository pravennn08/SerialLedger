# Source and maintenance

This repository distributes the SerialLedger C99/C++11 board library.
Development and the Python CLI are in <https://github.com/pravennn08/serial-ledger>.

Exported from the development working tree based on commit `48dad7c48cae0158aa20c315e7a292a28d640285`.
The export preserves source and example files, updates repository URLs,
and adds the API guide and registry validation workflow.

Make API changes in the development repository first, then export to a
fresh directory and review the changes before updating this repository.
Use a new library version for each subsequent registry release.
